# 板块资金监控

基于 AKShare 的本地监控网页，支持：

- 行业板块分钟级资金采样
- 概念板块分钟级资金采样
- 板块实时流入/流出排行
- 板块分钟净流入曲线
- 板块下钻个股资金流
- 个股实时资金榜

## 启动

```bash
uv sync
uv run uvicorn app.main:app --host 127.0.0.1 --port 8010
```

浏览器打开：

`http://127.0.0.1:8010`

## 说明

- 服务启动后会立即采样一次，并每分钟自动采样一次。
- 数据默认写入 `data/sector_fund_monitor.db`。
- 若 AKShare 临时请求失败，可在页面点击“立即采样”重试。
