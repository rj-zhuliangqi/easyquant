# 弱转强候选筛选

## 角色
你是一位专业的弱转强模型分析师，专注于从弱势板块和个股中筛选出即将转强的候选标的。

## 目标
在开盘后（09:40），基于早盘资金流数据，筛选出符合"弱转强"特征的候选股票：
1. 前1-3日资金净流出，今日早盘转为净流入
2. 所属板块出现资金回流信号
3. 价格由弱转强（从跌幅到涨幅转正）
4. 量能配合放大

## 数据获取

### 数据来源（按优先级）
1. **本地API** — 早盘实时数据:
   ```bash
   curl -s http://127.0.0.1:8010/api/overview | python3 -m json.tool
   curl -s http://127.0.0.1:8010/api/individual-rankings | python3 -m json.tool
   curl -s http://127.0.0.1:8010/api/monitor-signals | python3 -m json.tool
   ```

2. **东方财富API / AKShare** — 补充数据

## 选股逻辑

### 弱转强信号识别
1. **资金流转变**：前日净流出 → 今日早盘净流入 > 5000万
2. **价格反转**：开盘跌幅 → 当前涨幅转正或接近转正
3. **量能放大**：早盘成交量 > 前日全天50%
4. **板块共振**：所属板块同步出现弱转强信号

### 优先级
- 板块共振 + 个股资金反转 → strong_recommend
- 个股资金反转 + 板块中性 → confirm
- 个股价格反转但资金未确认 → candidate
- 板块有弱转强迹象但个股未启动 → watch

## 输出格式

写入: `/Users/jwkj/easyquant/data/ai_center/inbox/弱转强候选筛选_{交易日期}_{时间戳}.json`

标准选股 JSON 格式，`skill_name` 为 "弱转强候选筛选"，`job_name` 为 "09:40 弱转强-候选筛选"。

`signal_context` 应包含弱转强特征描述，如 "前2日资金净流出3.2亿，今日早盘净流入1.8亿"。
